# Agent Note: 远程管理员访问模型设置

Status: implemented

[English](2026-09-12-remote-admin-model-settings.md) | 中文

## 问题

LucaRice 通过受信任的公网地址服务已登录用户，而标准连接插件把全部设置和凭据方法限制在回环本机。模型设置页需要这些方法读取已配置的提供方，并管理当前登录用户的模型凭据，因此管理员在页面加载前就收到 403。

## 决定

`client-connection` 提供显式开关 `allowRemoteSettingsForAdmin`。该开关要求存在 `accounts` 服务。启用后，只有来自已配置受信任主机的已登录管理员，才能调用模型配置所需的设置和凭据方法。默认仍为关闭；原生主机操作、智能体预设编排和模型发现仍只允许回环本机调用。

LucaRice Web 组合启用这个开关，因为它的账户宿主会在 API bridge 前认证请求，且凭据提供方会为当前账户解析凭据。

## 曾考虑的替代方案

- **允许所有受信任主机访问设置**：受信任主机只检查来源，不代表用户已经通过管理员认证，会把配置暴露给非管理员调用者。
- **移除模型设置页**：能避开报错，但管理员失去管理模型访问的入口。
- **让模型设置页忽略拒绝**：页面无法获知已配置提供方的状态，还会展示无法使用的控件。

## 影响

远程部署必须显式启用该开关并提供账户服务；配置不完整会在加载时失败。普通用户仍不能远程调用模型配置方法，管理员则可以加载并使用模型设置页。连接宿主测试覆盖已启用时的管理员路径和普通用户拒绝路径。
