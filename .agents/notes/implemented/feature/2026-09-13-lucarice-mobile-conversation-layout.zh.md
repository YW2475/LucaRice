# Agent Note: LucaRice 移动端对话布局

Status: implemented

[English](2026-09-13-lucarice-mobile-conversation-layout.md) | 中文

## 问题

LucaRice 的空白会话 Hero、田块管理弹窗和了解智能体弹窗主要按桌面视口安排。手机上，固定高度的 Hero 会让输入框和快捷入口挤到浏览器控件附近，弹窗内容也难以阅读和触及。

## 决策

对话客户端插件为窄屏提供专用布局：Hero 可以纵向滚动，输入框下方为安全区留出空间，并缩小标语和快捷卡片的占用。快捷入口弹窗限制在手机视口内，标题保持可见，内容区域独立滚动。田块档案和农事时间轴会针对窄宽度重排；设置页田块编辑器保留适合触控的控件尺寸，并在需要时使用单列表单。移动端背景改为普通滚动，避免触屏浏览器中的固定背景问题。

## 备选方案

- 修改共享的 Harness 弹窗或应用框架会影响无关插件。
- 保留桌面尺寸后整体缩小内容会降低农事记录的可读性和可编辑性。
- 删除移动端田块信息会使其与同一份田块档案不一致。

## 影响

改动隔离在 LucaRice 的对话和田块管理插件中。桌面布局和田块数据读写保持不变，手机用户可以在不被浏览器控件遮挡的情况下滚动、阅读和编辑同一份记录。

## 验证

受影响的客户端 bundle 和聚焦组件测试可以成功构建。重启客户端插件后，已部署页面正常响应。
