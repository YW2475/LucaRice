# Agent Note: LucaRice 处理过程折叠

Status: implemented

[English](2026-09-12-lucarice-collapsed-processing-details.md) | 中文

## 问题

LucaRice 会在农事建议前把注入上下文、内部 Think 摘要和工具调用名称分别显示在对话中。这些技术过程打断了农户的阅读路径。

## 决策

ChatView 将连续的上下文、没有回答正文的纯 Think assistant 步骤和工具调用节点合并到一个默认关闭的原生展开项中。计数只包含会渲染的节点，不计入被抑制的田块影像上下文和不可见的工具调用头。用户消息和最终 assistant 回答保持直接可见。当一个 assistant 节点同时包含推理和回答时，回答保留在展开项外，并且不显示推理摘要。展开后复用每类过程行原有的渲染器。

## 备选方案

- 完全隐藏过程记录会移除可选的核对路径。
- 修改 Harness 会话日志会让改动超出客户端呈现范围。
- 分别折叠每一行仍会在对话中留下重复的技术条目。

## 影响

该行为属于对话客户端插件，不改变持久记录或 agent loop。过程行按需可见，并保留原有的工具和上下文呈现。

## 验证

聚焦的 ChatView 与 reasoning-row 测试覆盖默认关闭的过程展开项、展开行为和常规对话呈现。
